# Email-Format-Validator-using-Python
This project is a Python-based console application that validates the format of an email address entered by the user. It applies a set of logical checks to ensure that the email adheres to common formatting standards, such as the presence of an "@" symbol, correct domain extension, and valid characters. To enhance user interaction, the project uses the rich library to display colorful and styled messages, providing clear feedback on whether the email is valid or not.

The project serves as a practical implementation of string handling, input validation, and basic condition checking in Python, along with an introduction to third-party libraries for improving UI/UX in terminal applications.

✨ Key Features
✅ Email Format Validation

Checks for minimum length

Ensures the first character is an alphabet

Verifies a single "@" symbol

Validates domain extensions like .com, .in, etc.

Filters out invalid characters or whitespaces

🎨 Styled Terminal Output

Uses the rich library to print results in colored and formatted text

Displays success (green) and error (red) messages for better readability

🔄 Logical Error Codes

Shows specific error messages (e.g., Wrong Email 1 to 5) to help users understand the reason for invalidity

🧠 Educational Value

Great for beginners to learn string manipulation, conditional logic, and third-party library usage in Python

💻 User-Friendly Console Interface

Interactive input prompt

Clean and readable output
